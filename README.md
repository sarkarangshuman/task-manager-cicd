# 🚀 End-to-End CI/CD Pipeline using Jenkins & Docker

## 📌 Project Overview
This project demonstrates a complete CI/CD pipeline where code changes are automatically built and deployed using Jenkins and Docker.

---

## 🛠️ Tech Stack
- Git & GitHub  
- Jenkins  
- Docker  
- Node.js  
- ngrok  
- Postman  

---

## ⚙️ CI/CD Workflow
Code Push → GitHub → Webhook → Jenkins → Docker Build → Deploy → Live Application

---

## 🔄 Pipeline Stages
1. Clone code  
2. Build Docker image  
3. Stop old container  
4. Run new container  

---

## 🌐 Application Access
http://localhost:3001

---

## 🚀 Features
- Fully automated CI/CD pipeline  
- Dockerized deployment  
- Auto build on Git push

## 🧠 Key Learnings
